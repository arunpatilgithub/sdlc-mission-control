# Knowledge base placeholders

These files reserve a human-maintained home for repository and harness lessons. Entries begin as
`seeded` so a developer can review them before a future loader treats them as `approved`.
They are intentionally inert: no Planning, Develop, review, or Publish code loads them yet.

Add an entry only after a developer reviews its source or work-item evidence. Runtime mission
artifacts may propose a lesson, but agents must not promote one into these files themselves.
